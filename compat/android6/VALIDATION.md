## 校验与回归

- 57 项原生、打包、签名、校验、快照隔离和源适配脚本测试全部通过。
- 两种 ARM 原生播放器从当前固定源码编译，实际 ELF 的 Android SDK 标记均为
  23；PGS、JNI、MediaCodec 与 16 KB 对齐检查通过。
- 兼容 Gradle 清单新增的 366 项构件均由官方仓库重新核验 SHA-256，无冲突；
  与现代版相同坐标的校验值没有变化。
- 重新生成副本后比较 177 个应用源码和构建配置文件，与实际构建副本一致。
- 旧 SDK 静态分析无错误、无警告；保留两条测试文件的多余 import 提示。
- 六个定向 Flutter 测试文件共 52 项：50 项通过，2 项失败。
  其中来源目录的 AI 配置提示断言在未修改的现代版也失败；相册静默断言在
  兼容版与现代版独立重跑均通过，属于本次组合执行中的时序失败，不能将整组
  测试描述为全部通过。后台无新帧暂停、快速恢复、图片加载、遥控和配对相关
  场景已通过。补充图片居中、旋转缩放、双指与遥控测试 2 项通过。
- 已有现代 ARM64 APK 重新通过 API 24、签名和 16 KB 对齐校验。

构建摘要见 `artifacts/build-android-legacy.json`；官方构件核验、源码对照和
相关日志保存在 `artifacts/android6-validation/`。

## 隔离及未验证范围

主线客户端源码和依赖锁不降级，现代 Android 构建仍默认 API 24、Flutter
3.47.7。兼容转换只写入受标记保护的独立副本，API 23 原生产物使用独立缓存。
旧现代 Android 原生缓存缺少新增的 API 元数据，需要在下次构建时重建。
桌面和 Apple 构建配置未为本次兼容而更改。

本轮没有重新构建所有现代平台，也没有连接 Android 6 电视，不能据此保证
所有平台零回归或电视硬解已经正常。实际安装、启动、音视频与字幕、遥控、
后台暂停和恢复仍需设备验收。GitHub 工作流只完成本地静态检查，尚未在托管
runner 执行。未进行真机帧率或功耗测量，不据此宣称性能或续航提升。
