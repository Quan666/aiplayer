# v0.5.25 · 海报原图与缩放清晰度

源码版本：`0.5.25+31`，发布标签：`v0.5.25`。

- 海报查看器使用 TMDB 原图及 Bangumi 大图，识别已知缩略图地址并保留 URL 参数；未知来源保留原地址。
- 原图加载期间复用封面作为占位，继续使用磁盘缓存和有界解码队列。
- 双击或缩放手势结束后按显示尺寸、设备像素比例和放大倍数提升解码尺寸，上限为 4096 像素；缩小时复用已加载的高清图，避免手势过程中反复解码。
- 修复海报放大平移后原点移出视口、仍可见的图片却无法继续加载高清版本的问题。
- 包含 0.5.24 的离线下载、断点续传、本地目录管理、播放来源选择、系统媒体控制和弹幕改进；同步更新启动日志、关于信息、请求 User-Agent 及发布示例。

静态分析无问题，129 项定向 Flutter 回归及 14 项发布脚本测试全部通过，版本 / 标签一致性和差异检查通过。

Android 和 macOS 安装包由标签触发的 GitHub Actions 构建，远端结果需单独确认。本轮未重复执行全量测试，未进行原生打包或真机 profile/release 帧耗时及功耗测量。完整验证范围见 [验证记录](https://github.com/Quan666/aiplayer/blob/v0.5.25/docs/VALIDATION.md)。
