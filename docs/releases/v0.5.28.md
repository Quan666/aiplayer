# v0.5.28 · 弹幕匹配、目录集名与发布构建

源码版本：`0.5.28+34`，发布标签：`v0.5.28`。

- 弹幕搜索按作品名与季度选择唯一候选，支持首季候选省略季度后缀；遇到季度冲突或多个同名候选时保留后续匹配流程。
- 已识别目录新增文件后，复用已确认的作品资料补齐集名，保留已有集名，避免重新按文件名搜索导致作品关联丢失或误匹配。
- 统一 Android 通用、ARM64、Android 6.0 / 6.0.1 双 ARM 兼容版与 macOS 发布构建；按输入指纹复用固定的 Android 原生依赖，保留原证书和严格依赖校验。
- 修复 Android 发布模式插件注册与兼容版依赖校验，补充 DEX 版本及 API 23 v1 签名验证；完善原生依赖草稿发布重试。

发布前静态分析无问题，6 个 Flutter 测试文件共 87 项定向回归和 75 项发布脚本回归全部通过；供应链、版本 / 标签一致性、格式与差异检查通过。本轮未重复全量测试或本地安装包构建。

标签触发 GitHub Actions 构建上述四类安装包，全部成功后发布 Release。远端构建结果需单独确认；本轮未连接 Android / Android TV 真机，Android 6.0.1 现场安装问题仍待具体 APK 和设备错误码定位。完整验证范围见[验证记录](https://github.com/Quan666/aiplayer/blob/v0.5.28/docs/VALIDATION.md)。
