# v0.5.22 · 弹幕时间列表与目录识别修复

源码版本：`0.5.22+28`，发布标签：`v0.5.22`。

## 新增

- 弹幕面板增加“设置 / 列表”页签，显示已加载弹幕总数（筛选前）。搜索候选优先使用当前已加载剧集的实际数量，其余读取服务提供的数量；缺失时显示“数量未知”，不额外下载弹幕计数。
- 时间列表随播放、进度跳转及匹配 / 手动偏移定位，高亮最近到达的同一时间组；短弹幕紧凑显示，长弹幕自然换行。列表只构建可见行，切回设置或进入后台立即停止跟随，恢复时对齐最新时间；切换页签保留搜索草稿和设置滚动位置。

## 修复

- 统一本地与同步目录预览的缓存版本和上下文，修复已同步海报、集名等资料无法按当前缓存规则复用的问题。
- 目录内已有作品身份冲突时，仍按文件名补收缺失剧集；保留已有条目的身份和人工修改，不从冲突条目借用资料，也不错误合并为共享合集。

## 发布
