# v0.5.24 · 离线下载与本地视频管理

源码版本：`0.5.24+30`，发布标签：`v0.5.24`。

## 下载与本地目录

- 支持单个视频及整个文件夹离线下载，提供进度、暂停、继续、取消和断点续传；后台暂停传输，回到前台恢复非手动暂停的任务。
- 文件夹下载从所选目录开始保留子目录层级，不同来源及同名目录相互隔离，重复与重叠选择复用已有任务；修复部分剧集缺少媒体记录时漏下载的问题，并保留下载期间新删除的保护。
- 本地目录复用已识别资料显示封面和详情，集数与续播限定为目录内现有视频；同集不同版本合并展示，混合内容继续按普通文件夹浏览。
- 支持删除本地视频及文件夹，执行前确认并校验文件身份；应用管理的下载或导入副本可删除，仅链接的外部文件移除记录，保留远程原文件。

## 播放与弹幕

- 详情与播放器提供「切换版本与来源」，显示文件名、来源和视频规格；自动播放优先可用本地副本，同集候选按已知分辨率及码率选择，失效时尝试其他候选。
- Android 接入系统媒体会话，iOS / macOS 接入 Now Playing，Windows 接入系统媒体控制；共享当前播放会话的播放、暂停、前后集和进度控制，保留后台播放及 PiP 语义。
- 点击弹幕行可复制时间与完整正文；修复包含普通数字的句子被预设误过滤，修改播放时更新间隔后按新间隔重新计时。
- 修复混合中文与 URL 编码文件名的季集识别，完善播放器弹层关闭逻辑及控件阴影动画。

## 发布与验证

- 同步更新应用版本、启动日志、关于信息、请求 User-Agent 与发布示例；Android 和 macOS 安装包由标签触发的 GitHub Actions 构建，远端结果需单独确认。
- 本轮未进行原生构建、真实耳机或系统媒体路由验收、Android 真机 profile/release 帧耗时及功耗测量；自动测试不代表真机性能或续航结论。

发布候选在独立源码快照中完成静态分析，333 项定向 Flutter 回归与 14 项发布脚本测试全部通过，版本 / 标签一致性与差异检查通过。本轮未重复执行全量测试。完整验证范围见 [验证记录](https://github.com/Quan666/aiplayer/blob/v0.5.24/docs/VALIDATION.md)。
