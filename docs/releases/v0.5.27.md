# v0.5.27 · 相册、电视遥控与 Android 6 兼容构建

源码版本：`0.5.27+33`，发布标签：`v0.5.27`。

- 新增相册浏览、多格式照片组、图片缩放与幻灯片、个人视频和目录音乐播放；改进图片与视频封面复用、返回位置和焦点恢复，增加高级缓存设置。
- 完善电视方向键、确认、菜单、长按与分层返回操作；单击菜单进入顶部功能区，下键恢复原列表项目，双击菜单进入底部导航。支持手机遥控及密码输入。
- 增加文本查看与通用外部文件打开，修复 SMB 文件准备中等待关闭、无限排队和读取停滞的问题，显示实际传输进度，并保留后台取消和迟到结果隔离。
- 新增独立 Android 6.0 / 6.0.1 双 ARM 兼容构建入口，保留主线工具链；修正内置字体的默认字重，避免兼容版显示为细体。
- 加强原生依赖固定版本、摘要和签名校验，统一构建入口、安装包命名及验证记录。

发布前客户端静态分析无问题；21 个相关 Flutter 测试文件共 180 项通过、1 项因未启用真实 SMB 夹具跳过。Python 脚本回归 96 项通过、1 项因非 Windows 环境跳过；供应链、版本 / 标签一致性及差异检查通过。本轮未重复全量测试或本地安装包构建。

电视、相册与文件打开的组件回归、Linux 原生播放器和本机 SMB 验证范围见[电视验证记录](https://github.com/Quan666/aiplayer/blob/v0.5.27/docs/VALIDATION-TV-20261105.md)。Android 6 的既有构建记录对应旧版本 `0.5.26+32`，包含未通过用例，详见[兼容验证记录](https://github.com/Quan666/aiplayer/blob/v0.5.27/compat/android6/VALIDATION.md)，不代表本版安装包已经验收。

标签触发的 GitHub Actions 构建现代 Android 通用、Android ARM64 与 macOS 安装包；Android 6 兼容包使用独立手动工作流，远端构建结果需单独确认。当前未连接 Android / Android TV 真机，系统安装器、遥控键码、输入法、原生音量及性能与功耗尚未完成实机验证；Android 6.0.1 现场安装失败原因仍待设备错误码确认。完整历史范围见[验证记录](https://github.com/Quan666/aiplayer/blob/v0.5.27/docs/VALIDATION.md)。
