# v0.5.26 · 海报清晰度与桌面布局

源码版本：`0.5.26+32`，发布标签：`v0.5.26`。

- 海报按显示尺寸、设备像素比例与裁剪区域解码，普通卡片长边上限提升至 1280 像素；全屏查看器保留 4096 像素上限，避免低分辨率源图被放大解码。
- 在线源图与同步小图分层缓存，可见时按需升级旧缓存，高清图完成前保留已有画面；离线继续使用旧图，同步小图不会覆盖在线源图。
- 同步缩图改用面积平均缩放，优先调整 JPEG 质量，保留合规小图原字节和现有体积预算。
- 精简桌面侧栏，macOS 宽屏页头复用标题栏空间；标题区域支持拖动和双击，保留搜索、按钮、原生窗口控制与全屏交互。
- 同名无集号视频与电影的多个版本可共享作品资料；清理文件名尾部发布组标记，版本仍通过文件名区分。手动匹配读取最新记录，保留输入草稿并提示冲突原因。
- 下载、解码与缓存升级继续使用有界队列；离屏和后台停止非必要工作，恢复后按需继续。同步压缩在后台 isolate 执行。

静态分析无问题，30 个测试文件的 295 项定向 Flutter 回归和 14 项发布脚本测试全部通过，版本 / 标签一致性、格式与差异检查通过。本轮未重复执行全量测试。

Android 和 macOS 安装包由标签触发的 GitHub Actions 构建，远端结果需单独确认。Linux 软件渲染的既有 profile 报告不代表真机帧率或功耗；冷遍历和切页仍有超帧预算。本轮未执行原生打包、macOS AppKit 实机验收或 Android 真机性能与功耗测量。完整验证范围见 [验证记录](https://github.com/Quan666/aiplayer/blob/v0.5.26/docs/VALIDATION.md)。
