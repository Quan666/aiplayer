# v0.5.23 · 弹幕手动浏览与后台状态保存修复

源码版本：`0.5.23+29`，发布标签：`v0.5.23`。

## 弹幕列表

- 手动拖动、鼠标滚轮或键盘滚动后暂停自动跟随，正常播放、弹幕刷新和后台恢复保留浏览位置，当前弹幕仍继续高亮。
- 增加“回到当前”入口；点击该入口、主动跳转播放进度、切换剧集或调整时间偏移后恢复跟随。
- 保留紧凑行高、长文换行和惰性布局；刷新移除当前浏览窗口时安全定位到新列表末尾，继续保持手动浏览状态。

## 后台任务与封面

- 修复后台识别检查点和来源封面登记遇到 `database is locked` 的问题。数据库写入、同步时间戳和有界锁重试由复用的后台 isolate / 独立连接处理，避免界面线程等待写锁。
- 检查点仅保留一个在途写入与最新待写状态，普通进度通知不再反复重写任务列表；完成、取消、后台暂停和退出继续保存必要的恢复状态，空闲时不启动检查点 worker。
- 浏览封面请求按媒体去重并限制队列，后台立即取消非必要工作，恢复后继续；队列释放容量时让等待中的可见卡片重试。来源变更、缓存清理和销毁丢弃过期请求，未开启缩略图时不登记。
- 数据库修订升级至 schema v4，将任务检查点和浏览状态独立跟踪，避免这些后台写入使无关媒体、设置和位置缓存失效。
