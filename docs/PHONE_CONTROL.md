# 手机扫码控制

在应用的来源或相册入口打开“手机控制”，用同一局域网的手机扫码，在浏览器打开控制页。无需同步服务器或手机应用。电视可连接网线，手机可使用同一路由器下的 Wi-Fi；访客网络、客户端隔离、VPN 和系统局域网权限可能影响互通。

二维码配对有效期为 2 分钟，仅能建立一个手机会话。连接成功后配对窗口自动关闭；再次打开“手机控制”可查看状态或关闭控制。多网卡设备可以在配对窗口选择本机局域网地址。

## 操作

- 方向、确定和返回操作应用当前焦点，返回首页后不会关闭应用或操作电视系统桌面。
- 文字发送到当前选中的普通输入框，支持中文。输入目标或本机文字发生变化后，旧编辑会话失效；密码、验证码和其他受保护输入框拒绝手机输入，已有输入内容不会发送给手机。
- 播放、暂停、前后曲/集及快进退复用当前播放会话，快进退步长遵循应用设置。
- 相册通过页面自己的控制处理前后项、缩放、旋转和方向操作。

首版接收完整文字替换及确认输入；不提供系统级键盘注入、跨应用控制、系统开关机或互联网远程连接。

## 连接与生命周期

应用仅在用户打开手机控制后，在选中的一个本机 IPv4 局域网接口上监听临时端口。配对超时即关闭服务；已配对会话最长 2 小时，手机断开后保留 30 秒重连窗口，超时关闭。

应用进入 hidden/paused/detached 或销毁时，立即使指令失效并停止服务，不等待绘制下一帧。恢复前台后需要重新主动开启。控制服务不影响已有的用户后台音频/PiP 播放策略。

手机页面只按事件发送命令及接收状态，没有持续轮询。连接中断仅进行最多 3 次退避重连；页面在后台时暂停重试，恢复可见时可再尝试。过期会话需重新扫码。

## 实现与验证

HTTP、WebSocket、JSON 校验、随机配对/会话凭证及 QR 编码在独立 isolate 中执行。UI 仅接收经过验证的小型指令；当前操作和最多 8 条待处理命令有上限，过快请求、无效消息、重复编号和超时操作被拒绝或断开。

配对地址的短期凭证放在 URL fragment 中，页面读取后清除浏览器地址中的 fragment。控制会话使用不同随机凭证的 HttpOnly、SameSite=Strict Cookie，并校验 Host、Origin、客户端地址及单连接限制。此功能为普通局域网 HTTP 控制，不传输既有媒体来源密码、同步凭据或媒体直链，不支持向受保护输入框发送敏感凭据。

回归覆盖真实回环 HTTP/WebSocket 配对、错误 Origin、错误 Token、一次性配对、重复指令、队列取消、超时关闭及启动/停止竞态；组件回归覆盖焦点操作、过期文本编辑、密码字段拒绝和 paused 后不 pump 即停工。

这些测试不等同于 Android 电视、iPhone/Android 手机浏览器的真机验收。尚须验证目标电视、路由器隔离配置、Android/iOS/macOS 局域网权限和浏览器本地网络策略。
