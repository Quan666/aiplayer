# SQLite public domain

The unmodified SQLite 3.54.1 amalgamation is vendored under
`darwin/sqlite3_flutter_libs/Sources/CSQLite`. Its original public-domain
statements remain in both source files. SQLite is in the public domain:
https://www.sqlite.org/copyright.html

Source and hash provenance is recorded in `sqlite-source.lock.json`. The
plugin wrapper retains its separate upstream MIT license in `LICENSE`.
